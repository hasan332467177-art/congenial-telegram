# ربات تحلیل و محاسبات تلگرام

ربات برای همه کاربران تلگرام قابل استفاده است؛ محدود به تأسیسات ساختمان نیست.

## قابلیت‌ها
- تحلیل و پاسخ‌گویی عمومی به پرسش‌ها.
- انجام محاسبات ریاضی در گفت‌وگو.
- درج تاریخ و ساعت تهران در انتهای پاسخ‌های متنی.
- `/time [منطقه زمانی]`: نمایش ساعت.
- `/analyze HIGH LOW`: محاسبه دامنه و نسبت طبق فرمول قبلی:
  - `D = High - Low`
  - `R = D / (38 × 9.1)`
  - `درصد دامنه = D / Low × 100`
- `/calc`: فقط برای مالک و فقط در گفت‌وگوی خصوصی.

## نکته تحلیل بازار
این نسخه قیمت زنده یا کندل تاریخی را خودش واکشی نمی‌کند؛ برای تحلیل عددی بازار باید داده‌های سقف و کف را به ربات بدهید. گزارش محاسباتی، قیمت خام را نمایش نمی‌دهد و فقط نتایج محاسبه‌شده را می‌فرستد. زمان‌های هشدار خودکار قبلی هنوز در کد تعریف نشده‌اند، چون ساعت‌های دقیق در تنظیمات مخزن موجود نیست.

## امنیت
کلیدهای موجود در GitHub Secrets دست‌نخورده می‌مانند. هیچ کلید یا توکنی در کد قرار ندهید.
