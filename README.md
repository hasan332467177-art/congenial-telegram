# ربات تحلیل و محاسبات تلگرام

ربات برای همه کاربران تلگرام قابل استفاده است؛ محدود به تأسیسات ساختمان نیست.

- تحلیل عمومی و پاسخ به پرسش‌ها
- محاسبات ریاضی در متن گفت‌وگو
- اعلام تاریخ و ساعت تهران در پایان پاسخ‌ها
- `/time [منطقه زمانی]`: نمایش ساعت
- `/analyze HIGH LOW`: محاسبه D = High - Low، نسبت R = D / (38 ÷ 9.1) و درصد دامنه D / Low × 100
- `/calc`: فقط برای مالک و در گفت‌وگوی خصوصی

این نسخه فعلاً قیمت زنده یا کندل تاریخی را خودکار دریافت نمی‌کند؛ برای تحلیل عددی بازار باید سقف و کف داده‌شده را وارد کنید. زمان‌های هشدار خودکار بازار نیز هنوز در کد تنظیم نشده‌اند. کلیدهای فعلی GitHub Secrets دست‌نخورده باقی می‌مانند.
