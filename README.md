# ربات هوشمند تلگرام

ربات فارسی تلگرام با پاسخ‌گویی هوش مصنوعی، ساعت مناطق زمانی و محاسبات امن. هیچ هشدار زمان‌بندی‌شده‌ای ارسال نمی‌کند.

## امکانات
- `/start` و `/help`
- `/time` برای ساعت تهران و `/time Europe/Berlin` برای منطقه زمانی دلخواه
- `/calc 31/38/9.1` برای محاسبه عبارت ریاضی
- پاسخ به پیام‌های متنی با OpenAI Responses API
- امکان محدودسازی استفاده به شناسه عددی تلگرام مالک از طریق `ALLOWED_TELEGRAM_USER_ID`

## راه‌اندازی
1. مقادیر `TELEGRAM_BOT_TOKEN` و `OPENAI_API_KEY` را در محیط اجرا وارد کنید؛ کلیدها را در کد یا Git ثبت نکنید.
2. `OPENAI_MODEL` به‌صورت پیش‌فرض `gpt-4.1-mini` و `DEFAULT_TIMEZONE` به‌صورت پیش‌فرض `Asia/Tehran` است.
3. برای محدود کردن ربات، مقدار خصوصی `ALLOWED_TELEGRAM_USER_ID` را با شناسه عددی مالک تنظیم کنید.
4. با Docker اجرا کنید: `docker build -t congenial-telegram .` سپس کانتینر را با متغیرهای محیطی اجرا کنید.

## استقرار Render
فایل `render.yaml` یک Background Worker مبتنی بر Docker تعریف می‌کند. در Render از New > Blueprint و مخزن GitHub استفاده کنید؛ سپس مقادیر محرمانه را در فرم محیطی وارد کرده و سرویس را ایجاد کنید. Worker باید به‌صورت پیوسته اجرا شود؛ GitHub Actions فقط تست است و میزبان دائمی ربات نیست.

## بررسی خودکار
GitHub Actions با هر push و pull request وابستگی‌ها را نصب و فایل پایتون را از نظر نحوی بررسی می‌کند.

## متغیرهای محیطی
به `.env.example` مراجعه کنید. توکن تلگرام و کلید OpenAI را در پیام عمومی یا فایل‌های مخزن قرار ندهید.
