# ربات عمومی تاسیسات ساختمان

ربات برای همه کاربران تلگرام باز است و فقط به پرسش‌های مرتبط با تاسیسات ساختمان پاسخ می‌دهد.

## قابلیت‌ها
- `/start` و `/help`: برای همه کاربران.
- گفت‌وگوی عمومی درباره HVAC، تهویه، گرمایش و سرمایش، لوله‌کشی، برق، آتش‌نشانی، BMS، انرژی و نگهداری.
- `/time`: نمایش ساعت.
- `/calc`: فقط در گفت‌وگوی خصوصی و برای شناسه مالک که در `ALLOWED_TELEGRAM_USER_ID` تنظیم شده باشد.
- کلیدها فقط از GitHub Actions Secrets خوانده می‌شوند؛ در کد یا فایل‌های مخزن ذخیره نشده‌اند.

## اجرای خودکار
فایل `.github/workflows/run-bot.yml` ربات را با GitHub Actions اجرا می‌کند:
- اجرای دستی از تب Actions نیز ممکن است.
- زمان‌بندی هر ۵ دقیقه بررسی می‌شود.
- هر اجرای ربات حداکثر حدود ۵ ساعت و ۵۰ دقیقه فعال می‌ماند تا اجرای بعدی ادامه دهد.
- این روش اجرای پیوسته واقعیِ سرور اختصاصی نیست و ممکن است بین اجراها وقفه کوتاهی داشته باشد.

## Secrets موردنیاز
- `TELEGRAM_BOT_TOKEN`
- `OPENAI_API_KEY`
- `ALLOWED_TELEGRAM_USER_ID` (اختیاری؛ برای فعال‌کردن دستور خصوصی `/calc` شناسه عددی مالک را در این Secret قرار دهید.)

دو Secret اول از قبل در مخزن ثبت شده‌اند و این تغییر آن‌ها را دست‌کاری نمی‌کند.
